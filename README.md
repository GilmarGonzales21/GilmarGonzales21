# Gilmar Gonzales

Desarrollo sitios y aplicaciones web orientados a necesidades reales de negocio. Aquí presento dos proyectos publicados y las decisiones técnicas detrás de ellos.

## Proyectos destacados

### Nexo Negocio · sitio de servicios digitales

**[Ver sitio publicado](https://nexo-negocio-web.vercel.app/)**

**Objetivo:** explicar servicios de desarrollo web, software y análisis de datos, mostrar trabajos y facilitar el primer contacto con posibles clientes.

**Mi trabajo:** diseñé una experiencia adaptable a móvil y escritorio, páginas específicas para cada servicio, una sección de proyectos, un formulario de contacto y una identidad visual interactiva. Preparé el sitio para Vercel e incorporé metadatos, navegación por teclado y preferencias de movimiento.

**Decisiones técnicas:** sitio estático con HTML, CSS y JavaScript; scripts en Python para generar y preparar las páginas publicadas. La analítica se carga solo con consentimiento del visitante.

**Estado:** sitio publicado. La recepción de consultas mediante el formulario requiere una comprobación final con un envío real.

### Noble Import · tienda de iPhones

**[Ver tienda publicada](https://nobleimport.store/)**

**Objetivo:** presentar modelos, variantes y disponibilidad, y permitir que una persona consulte o inicie una reserva con información clara.

**Mi trabajo:** desarrollé catálogo, búsqueda y filtros, fichas de producto con variantes, carrito persistente y flujos de consulta y reserva. El proyecto también incluye panel de administración, modelo de datos, migraciones y pruebas de reglas de negocio.

**Decisiones técnicas:** Next.js y TypeScript para la aplicación; PostgreSQL y Supabase para los datos y el acceso administrativo. Las pruebas de base de datos usan PostgreSQL embebido.

**Estado:** la tienda y el catálogo están publicados. Los modelos destacados figuran como próximos ingresos; la activación de cobros y la operación con servicios externos aún requieren configuración y pruebas reales.
